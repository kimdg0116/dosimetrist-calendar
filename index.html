아이폰갤럭시 위젯 설치

  1. 아래 파트 위젯 받기를 눌러 파일을 받습니다.파트 위젯 받기
  2. 받은 파일(part-widget.apk)을 열어 설치. 크롬이 "이 출처의 앱 설치"를 물으면 허용한 뒤 다시 설치합니다.
  3. 홈 화면 빈 곳을 길게 누름 → 위젯 → 파트 위젯을 끌어다 놓습니다.
  4. 뜨는 화면에 접근 코드(앱과 같은 6자리)를 넣고 A·B 중 고른 뒤 저장.
  5. 아래 위젯 색 맞추기를 누르면 위젯이 지금 앱 테마 색으로 바뀝니다. 테마 색을 바꿀 때마다 한 번 누르세요.

알아 두기

위젯을 누르면 이 앱이 열립니다. A·B나 접근 코드는 위젯을 길게 눌러 설정에서 바꿉니다. 위젯은 30분마다 새로 그려지고 폰의 라이트·다크를 따라갑니다. 위젯 전용이라 앱 목록에 아이콘은 생기지 않습니다.

새 버전은 위젯이 몇 시간마다 확인해 스스로 설치합니다. 처음 한 번은 위젯에 "새 버전이 있습니다 · 눌러서 설치"가 뜨는데, 누르고 이 출처 허용을 켜 주면 그다음부터는 손댈 필요가 없습니다. (버전 7부터, 그 전 버전은 위 받기로 한 번 더 설치)

  1. App Store 에서 Scriptable 설치Scriptable 받기
  2. 아래 설치 코드 복사를 누릅니다.
  3. Scriptable 을 열고 오른쪽 위 ＋ → 빈 화면에 붙여넣기 → 맨 위 제목을 파트 위젯 으로 바꾸고 Done.
  4. 목록의 파트 위젯을 한 번 눌러 실행 → 접근 코드(앱과 같은 6자리) 입력 → A·B 미리보기로 확인.
  5. 홈 화면 빈 곳을 길게 누름 → 왼쪽 위 ＋ → Scriptable → 중간 크기 추가.
  6. 추가한 위젯을 길게 눌러 위젯 편집 → Script: 파트 위젯 · Parameter: A 또는 B.

    색을 고정하려면 뒤에 붙입니다: A 라이트 · B 다크. 폰이 라이트인데 위젯만 어둡다면 홈 화면 길게 누름 → 편집 → 사용자화 → 자동을 확인하세요.

  7. 아래 위젯 색 맞추기를 누르면 Scriptable 이 열리며 위젯이 지금 앱 테마 색으로 바뀝니다. 테마 색을 바꿀 때마다 한 번 누르세요.

설치 코드


  
  
한 번만 붙여넣으면 됩니다. 위젯이 고쳐지면 자동으로 최신이 됩니다. Scriptable 목록에 dosimetrist-widget-core 가 같이 생기는데 위젯 본체라 지우지 마세요.

  
A · B

  
A 오늘 업무 + 오늘 일정 · B 오늘·내일 일정(참석 인원) + 당직·온콜. 위젯은 iOS 가 정한 때(보통 15~30분)에 새로 그려집니다. 접근 코드는 그 폰 안(키체인)에만 저장됩니다.
